### Canonical engine names

- **Engine 1 — Causal & Continuity State Spine** (Canonical State, Identity, and Adaptation Lineage Substrate)
- **Engine 2 — Deterministic Effect Gate / End-to-End Authority & Consequence Integrity Pipeline** (Inline Policy, Network Authority & Kernel Sandbox) [PRIMARY WEDGE]
- **Engine 3 — Procedural Skill Compilation & Verified Adaptation Engine** (Procedural-Family Abstraction & Verifier-Gated Skill Governance)

Three physical engines only. Goal Contract, migration semantics, team-state, world-state, and governance research are conceptual layers or experimental modules — not additional daemons.

### Broad positioning (V4)

> **GIBBRN investigates continuity and integrity for long-lived adaptive agents.**

> **GIBBRN investigates how long-lived adaptive agents can change models, runtimes, memory representations, skills, tools, collaborators, and execution environments while preserving canonical identity, authority, provenance, validated competence, objective integrity, and end-to-end consequence integrity.**

This is a research hypothesis/program, not an established guarantee.

*North-star sentence (retained):*
> **Agents can change. Their integrity must persist.**

*North-star research question (V4):*
> **How can a long-lived autonomous system change its cognition, models, memory, skills, tools, runtime, environment, and collaborators without losing its identity, intended objective, validated competence, delegated authority, or the integrity of the consequences it produces?**

The V3 question — *which agent state may safely remain probabilistic and model-maintained, and which state must remain canonical, deterministic, provenance-preserving, validated, versioned, and externally enforced?* — is retained as the subordinate foundational question (RQ1).

### Three-year program shape

- **YEAR 1 (M1–M12) — ACT SAFELY:** State semantics; causal continuity; authority + consequence integrity; verified skills.
- **YEAR 2 (M13–M24) — CHANGE SAFELY:** Skill portability; long-horizon survival; model/runtime migration; objective/evaluation integrity.
- **YEAR 3 (M25–M36) — PERSIST TOGETHER (conditional):** Decision-sufficient environment state; team continuity; shared-state governance; integrated persistent-agent validation. Activates only if earlier gates justify expansion.
